=========================================================
   WORLD CUP DATABASE MANAGER - STAGE 5
   הוראות התקנה והפעלה
=========================================================

דרישות מקדימות:
- Docker מותקן ומור
- קובץ .env בתיקיית הפרויקט הראשית עם המשתנים הנדרשים

=========================================================
א. התקנת מסד הנתונים בפקודה אחת
=========================================================

1. העתק את תיקיית הפרויקט למחשבך.

2. הרץ את התקנת המסד:
   docker compose --profile setup run --rm setup

3. הרץ את מסד הנתונים + האפליקציה:
   docker compose up -d db web

4. פתח בדפדפן: http://localhost:5000

=========================================================
ב. עצירת האפליקציה
=========================================================

   docker compose down

=========================================================
ג. הרשאות
=========================================================

- משתמש רגיל: צפייה בלבד בכל המסכים
- מנהל (Admin): לחץ על כפתור Admin בשורת הניווט,
  הזן קוד (ברירת מחדל: admin_code123).

=========================================================
ד. ארכיטקטורת הקבצים
=========================================================

stage_5/

    views/                 - 17 Views
    functions/             - 3 פונקציות
    procedures/            - 21 פרוצדורות CRUD

=========================================================
