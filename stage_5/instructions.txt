=========================================================
   WORLD CUP DATABASE MANAGER - STAGE 5
=========================================================

דרישות מקדימות:
- Docker מותקן ומור�
- Python 3.8+ מותקן (להרצת האפליקציה בלבד)

=========================================================
א. התקנת מסד הנתונים בפקודה אחת
=========================================================

1. העתק את תיקיית הפרויקט למחשבך.

2. הרץ את הפקודה הבאה מתוך תיקיית הפרויקט:
   docker compose --profile setup run --rm setup

   פקודה זו מבצעת הכל אוטומטית:
   - יוצרת את כל אובייקטי המסד (טבלאות, Views, פונקציות, פרוצדורות, טריגרים)
   - מייבאת נתוני מונדיאל (PERSON, TEAM, PLAYER, REFEREE, STADIUM, MATCH, MATCH_EVENT, PLAYER_MATCH_STATS)
   - מייבאת נתוני הימורים (users, matches, odds, bets, teams, transactions)
   - מריצה אינטגרציה (GLOBAL_MATCH, match_id -> global_match_id)
   - מחילה אילוצים (MATCH_EVENT.Minute TEXT -> INTEGER)

3. הרץ את מסד הנתונים (אם אינו רץ כבר):
   docker compose up -d db

=========================================================
ב. הרצת אפליקציית ה-Web
=========================================================

1. נווט לתיקיית stage_5:
   cd stage_5

2. התקן חבילות Python נדרשות:
   pip install flask psycopg2-binary python-dotenv

3. ודא שקובץ .env בתיקיית הפרויקט הראשית מכיל:
    DB_USER_SECRET=user_db
    DB_PASSWORD_SECRET=password_db
    DB_NAME_SECRET=world_cup_db
    DB_HOST=localhost
    DB_PORT=5432
    ADMIN_CODE=admin_code123

4. הרץ את האפליקציה:
   python app.py

5. פתח בדפדפן: http://localhost:5000

=========================================================
ג. הרשאות
=========================================================

- משתמש רגיל: צפייה בלבד בכל המסכים
- מנהל (Admin): לחץ על כפתור Admin בשורת הניווט,
  הזן קוד (ברירת מחדל: admin_code123).
  לאחר ההתחברות יופיעו אפשרויות עריכה, הוספה ומחיקה.

=========================================================
ד. ארכיטקטורת הקבצים
=========================================================

stage_5/
  app.py                   - כניסת האפליקציה (Flask)
  db_connection.py         - חיבור למסד + פונקציות עזר
  routes/                  - 10 מודולי ניתוב, אפס SQL
  templates/               - תבניות HTML (Bootstrap 5)
  setup/
    setup.sh               - סקריפט התקנה מלא (רץ דרך Docker)
  sql/
    full_install.sql       - יצירת מבנה המסד בלבד
    install.sql            - תוספות שלב 5 בלבד
    views/                 - 17 Views (JOIN/GROUP BY מורכבים)
    functions/             - 3 פונקציות
    procedures/            - 21 פרוצדורות CRUD

=========================================================
ה. מסכי המערכת
=========================================================

1. Home       - דשבורד עם סטטיסטיקות
2. Teams      - ניהול נבחרות + שחקנים ומשחקים
3. Players    - ניהול שחקנים + אירועים
4. Matches    - ניהול משחקים + אירועים וסטטיסטיקות
5. Stadiums   - ניהול אצטדיונים
6. Referees   - ניהול שופטים
7. Events     - ניהול אירועי משחק
8. Reports    - 3 שאילתות מוגדרות מראש
9. Procedures - הפעלת פונקציות ופרוצדורות (דרוש Admin)

=========================================================
ו. התקנה ידנית (ללא Docker)
=========================================================

אם אינך משתמש ב-Docker, הרץ לפי הסדר:

1. צור את המבנה:
   psql -U user_db -d world_cup_db -f stage_5/sql/full_install.sql

2. ייבא נתוני מונדיאל:
   python stage_1/Programing/generate_data.py

3. ייבא נתוני הימורים:
   psql -U user_db -d world_cup_db -f stage_3/backup2.sql

4. אינטגרציה:
   psql -U user_db -d world_cup_db -f stage_3/Integrate.sql

5. אילוצים:
   psql -U user_db -d world_cup_db -f stage_2/Constraints.sql
