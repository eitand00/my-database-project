=========================================================
   WORLD CUP DATABASE MANAGER - STAGE 5
   הוראות הפעלה של האפליקציה (WEB VERSION)
=========================================================

דרישות מקדימות:
1. PostgreSQL מורץ (Docker) על localhost:5432
2. בסיס הנתונים world_cup_db מאותחל עם כל הטבלאות, הנתונים,
   הפונקציות והפרוצדורות משלבים 1-4
3. Python 3.8+ מותקן

התקנה:
--------
1. התקנת החבילות הנדרשות (מתוך תיקיית stage_5):
   pip install flask psycopg2-binary python-dotenv

2. קובץ .env בתיקיית הפרויקט (my-database-project):
    DB_USER_SECRET=user_db
    DB_PASSWORD_SECRET=password_db
    DB_NAME_SECRET=world_cup_db
    DB_HOST=localhost
    DB_PORT=5432
    ADMIN_CODE=admin123

3. יש לוודא שקובץ `.env` בתיקיית הפרויקט (my-database-project) מכיל
   `ADMIN_CODE` עם הקוד הרצוי (ברירת מחדל: `admin_code123` ב-.env המצורף)

4. התקנת הפרוצדורות והפונקציות (אם עדיין לא מותקנות):
   docker compose exec db sh -lc 'psql -U user_db -d world_cup_db -f /stage_5/Procedures_Functions.sql'
   
   (יש לוודא שהתיקיה stage_5 מותקנת ב-container)

הרצה:
------
   cd stage_5
   python app.py

המערכת תהיה זמינה בדפדפן בכתובת:
   http://localhost:5000

הרשאות:
---------
- **משתמש רגיל** - צפייה בלבד בכל המסכים ללא אפשרויות עריכה
- **מנהל (Admin)** - לחיצה על כפתור Admin בשורת הניווט, הזנת קוד המנהל
  (ברירת מחדל: admin123, מוגדר במשתנה הסביבה ADMIN_CODE)
  לאחר התחברות יופיעו כל אפשרויות העריכה, ההוספה והמחיקה

מסכי המערכת:
--------------
1. **דף הבית** (Home) - תצוגת סטטיסטיקות כלליות + ניווט מהיר
2. **Teams** - ניהול נבחרות: הוספה, עריכה, מחיקה + רשימת שחקנים ומשחקים
3. **Players** - ניהול שחקנים: הוספה, עריכה, מחיקה + אירועי משחק
4. **Matches** - ניהול משחקים: הוספה, עריכה, מחיקה + אירועים וסטטיסטיקות
5. **Stadiums** - ניהול אצטדיונים
6. **Referees** - ניהול שופטים
7. **Events** - ניהול אירועי משחק
8. **Queries** - הרצת שאילתות Select (שלב 2):
   - משחקים עם 3+ שערים ב-2018
   - אצטדיונים גדולים עם כרטיסים אדומים
   - נבחרות עם 2+ שערים
   - עורך SQL חופשי
9. **Procedures** - הרצת פרוצדורות/פונקציות (שלב 4):
   - זמין לכל המשתמשים ללא הגבלה
   - Calculate Potential Payout (פונקציה)
   - Get Match Bettors (Ref Cursor, פונקציה)
   - Mass Update Stage Odds (פרוצדורה)
   - Create Bet (פרוצדורה)

עקרונות:
---------
- **FK מוצגים כשמות** - כל המפתחות הזרים מוחלפים בשמות (JOIN)
- **עדכון** - טופס עריכה נפרד לכל ישות
- **מחיקה** - עם אישור משתמש (confirm dialog)
- **עיצוב רספונסיבי** - מבוסס Bootstrap 5
- **שגיאות** - מוצגות כ-flash messages בחלק העליון
