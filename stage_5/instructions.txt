=========================================================
   WORLD CUP DATABASE MANAGER - STAGE 5
   הוראות התקנה והפעלה
=========================================================

דרישות מקדימות:
- PostgreSQL מורץ (Docker) על localhost:5432
- Python 3.8+ מותקן

=========================================================
א. התקנת מסד הנתונים (שלב 1-4)
=========================================================

1. העתק את תיקיית הפרויקט (my-database-project) למחשב שלך.

2. הרץ את קובץ ההתקנה המלא מתוך תיקיית הפרויקט:
   psql -U user_db -d world_cup_db -f stage_5/sql/full_install.sql

   קובץ זה יוצר את כל אובייקטי המסד:
   - 8 טבלאות מונדיאל (PERSON, TEAM, PLAYER, REFEREE, STADIUM, MATCH, MATCH_EVENT, PLAYER_MATCH_STATS)
   - 6 טבלאות הימורים (users, matches, odds, bets, teams, transactions)
   - טבלת GLOBAL_MATCH לאינטגרציה
   - אילוצים (constraints) על קיבולת אצטדיון, דקות אירוע, שלבי טורניר
   - 19 Views (2 משלב 3 + 17 משלב 5)
   - 4 פונקציות (Calculate_Potential_Payout, Get_Match_Bettors_RefCursor, Get_Match_Bettors, + 2 trigger functions)
   - 2 טריגרים (payout_on_win, prevent_negative_balance)
   - 25 פרוצדורות (create_user, create_odd, create_bet, Mass_Update_Stage_Odds + 21 CRUD sp_*)

   הערה: קובץ זה יוצר מבנה בלבד. יש לייבא נתונים בנפרד
   (ראה סעיף ב).

3. לחלופין, ניתן להתקין רק את תוספות שלב 5 על גבי מסד קיים:
   cd stage_5/sql
   psql -U user_db -d world_cup_db -f install.sql

=========================================================
ב. ייבוא נתונים
=========================================================

הנתונים לא כלולים בקובץ ההתקנה. יש לייבא אותם כך:

1. נתוני מונדיאל - הרץ את ה-ETL דרך Docker:
   docker compose --profile import run --rm importer

2. נתוני הימורים - שחזר מגיבוי:
   psql -U user_db -d world_cup_db -f stage_3/backup2.sql

=========================================================
ג. הרצת אפליקציית ה-Web
=========================================================

1. נווט לתיקיית stage_5:
   cd stage_5

2. התקן חבילות Python נדרשות:
   pip install flask psycopg2-binary python-dotenv

3. ודא שקובץ .env בתיקיית הפרויקט הראשית מכיל:
    DB_USER_SECRET=user_db
    DB_PASSWORD_SECRET=password_db
    DB_NAME_SECRET=world_cup_db
    DB_HOST=localhost
    DB_PORT=5432
    ADMIN_CODE=admin_code123

4. הרץ את האפליקציה:
   python app.py

5. פתח בדפדפן: http://localhost:5000

=========================================================
ד. הרשאות
=========================================================

- משתמש רגיל: צפייה בלבד בכל המסכים
- מנהל (Admin): לחץ על כפתור Admin בשורת הניווט,
  הזן קוד (ברירת מחדל: admin_code123).
  לאחר ההתחברות יופיעו אפשרויות עריכה, הוספה ומחיקה.

=========================================================
ה. ארכיטקטורת הקבצים
=========================================================

stage_5/
  app.py                   - כניסת האפליקציה (Flask)
  db_connection.py         - חיבור למסד + פונקציות עזר
  routes/                  - 10 מודולי ניתוב, אפס SQL
    teams.py, players.py, matches.py, stadiums.py,
    referees.py, events.py, auth.py, procs.py,
    reports.py, __init__.py
  templates/               - תבניות HTML (Bootstrap 5)
  sql/
    full_install.sql       - התקנת כל המסד בקובץ אחד
    install.sql            - התקנת תוספות שלב 5 בלבד
    views/                 - 17 Views (JOIN/GROUP BY מורכבים)
    functions/             - 3 פונקציות
    procedures/            - 21 פרוצדורות CRUD

=========================================================
ו. מסכי המערכת
=========================================================

1. Home       - דשבורד עם סטטיסטיקות
2. Teams      - ניהול נבחרות + שחקנים ומשחקים
3. Players    - ניהול שחקנים + אירועים
4. Matches    - ניהול משחקים + אירועים וסטטיסטיקות
5. Stadiums   - ניהול אצטדיונים
6. Referees   - ניהול שופטים
7. Events     - ניהול אירועי משחק
8. Reports    - 3 שאילתות מוגדרות מראש
9. Procedures - הפעלת פונקציות ופרוצדורות (דרוש Admin)
